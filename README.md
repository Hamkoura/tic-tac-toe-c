# Tic-Tac-Toe in C

A console-based Tic-Tac-Toe game developed in C as a team project during our first year at ECE Paris.

## Features

- Two-player gameplay (X and O)
- 3×3 interactive game board
- Win and draw detection
- Input validation
- Individual player time tracking
- Game history saved to a text file

## Project Structure

- `main.c` — Main game loop and program execution
- `Morpion.c` — Game logic and functions
- `Morpion.h` — Function prototypes and project definitions
- `historique_morpion.txt` — Game history

## Technical Concepts

This project allowed us to practice several fundamental C programming concepts:

- Functions and modular programming
- Arrays and pointers
- Header files
- File handling
- Input validation
- Time measurement with `clock()`
